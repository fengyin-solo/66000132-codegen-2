# 生成艺术 SVG 海报设计器

参数化生成艺术工具，支持螺旋、分形树、波浪、圆环、噪声场五种图案，8 种颜色主题，SVG/PNG 导出。

## 功能

- 5 种图案类型：螺旋、分形树、波浪、圆环、噪声场
- 可编辑色板列表：
  - 8 套预设色板（日落、海洋、霓虹、森林、单色、糖果、火焰、极光）均可逐格改色与命名，改坏了可一键「还原内置」
  - 从任意一套现有配色（含自定义色板）「复制」出新的一套，保存后立即套用
  - 色板以卡片纵向排列，点击卡片即套用
  - 色值实时校验：非法值会红框标出具体是哪一格并给出提示，修正前无法保存，不会悄悄退回默认色
  - 删除自定义色板前弹窗确认；删除正在使用的色板会明确告知影响（画面立即回退到第一套）
- 深 / 浅画面底色切换：在深色 `#030712` 与浅色 `#f8fafc` 之间切换，实时预览色板落在画面上的效果
- 本地持久化（localStorage）：自定义色板、内置色板的修改、当前选中色板与底色模式在刷新 / 退回首页再进来后保持同步
- 种子随机数生成器（确定性重现）
- 参数实时预览：迭代数、缩放、旋转、描边、透明度
- SVG 矢量导出 & PNG 高清导出

## 技术栈

- React + TypeScript + Vite
- D3.js（数据处理）
- Zustand（状态管理）
- Tailwind CSS

## 运行

```bash
cd frontend && npm install && npm run dev
```
